# Sistema de gerenciamento de biblioteca <br> (Somente Java puro)

Este é um projeto pessoal feito para estudos e prática focada na lógica de programação em Java puro.


# Resumo do projeto
Sistema de gerenciamento de biblioteca para controle de livros e revistas emprestadas.
<br>
<br>

<H3> Funcionalidades previstas para o sistema: </H3>

<H4> Para funcionários: </H4>
- Cadastro de usuários; <br>
- Cadastro de autores; <br>
- Cadastro de Livros ou Revistas; <br>
- Consulta de usuários cadastrados no sistema e seus respectivos livros/revistas emprestados; <br>
- Consulta de autores cadastrados; <br>
- Consulta de Livros/revistas cadastrados. <br>

<H4> Para usuários: </H4>
- Pegar livro ou revista emprestado; <br>
- Devolver item emprestado; <br>
- Consultar todos os livros/revistas cadastrados; <br>
- Consultar autores cadastrados; <br>
- Procurar um livro por autor. 
<br>
<br>

<H3> Tecnologias e conceitos utilizados neste projeto: </H3>
- Java 25 (Sintaxe em geral sem uso de framework). <br>
- Orientação a objetos. <br>
- Scanner (para entrada de dados no terminal). <br> 
- Collections. <br> 
- Documentação (comentários para entender melhor o código).
- Versionamento de código com GIT e commits com descrições claras para controle e histórico de código.
<br> <br>

Essa primeira parte do projeto foi realizada apenas com 3 principais tecnologias, sendo elas: <br> <b>Java</b> puro para treinar sintaxe, <b>Scanner</b> para entrada de dados no terminal para testar o sistema e <b>ArrayList</b> para guardar objetos/informações e poder buscar esses objetos/informações guardados em memória com o sistema em execução, uma vez que não foi usado banco de dados.

Este projeto será evoluído com o tempo e será adicionado novas funcionalidades.
A ideia é transformar esse projeto simples, que atualmente funciona somente no back-end com Scanner para entrada de dados no terminal, em um projeto FULL STACK, escalável, com utilização de banco de dados, interface interativa, código limpo e documentado.

Este projeto não será mais evoluído neste repositório para preservar os commits feitos e seguir boas práticas do mercado, além de futuramente poder comparar este projeto simples, feito com Java e Scanner, com o projeto final utilizando Spring boot, mySQL, React, entre outras tecnologias. <br>
