# Sistema de gerenciamento de biblioteca

Este é um projeto pessoal para estudos e prática focada na programação back-end em Java.

O projeto será evoluído com o tempo e será adicionado novas funcionalidades.
A ideia é transformar esse projeto simples, que atualmente funciona somente no back-end com Scanner no terminal, em um projeto FULL STACK, escalável, com utilização de banco de dados, interface interativa, código limpo e documentado.
Esse projeto será usado para mostrar meu avanço nos estudos da programação back-end na linguagem Java.

# Resumo do projeto
Sistema de gerenciamento de biblioteca que poderá ser usado tanto por um funcionário como para um usuário, pois o sistema mostrará interfaces e opções diferentes para cada um.

<H3> Tecnologias utilizadas no projeto: </H3>
- Java (atualmente usando) <br>
  &nbsp;&nbsp; - Scanner para entrada de dados <br>

  Quando esse projeto começar a evoluir para FULL STACK, será alterado o campo de Tecnologias utilizadas e será colocado todas as tecnologias que irei usar e será usado este mesmo repositório.
