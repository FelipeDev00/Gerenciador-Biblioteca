# Sistema de gerenciamento de biblioteca <br> (primeira parte concluída)

Este é um projeto pessoal para estudos e prática focada na programação back-end em Java.

O projeto será evoluído com o tempo e será adicionado novas funcionalidades.
A ideia é transformar esse projeto simples, que atualmente funciona somente no back-end com Scanner no terminal, em um projeto FULL STACK, escalável, com utilização de banco de dados, interface interativa, código limpo e documentado.
Esse projeto será usado para mostrar meu avanço nos estudos da programação back-end na linguagem Java.

# Resumo do projeto
Sistema de gerenciamento de biblioteca que poderá ser usado tanto por um funcionário, como para um usuário, pois o sistema mostrará interfaces e opções diferentes para cada um.

<H3> Tecnologias utilizadas nesta primeira parte do projeto: </H3>
- Java <br>
- Scanner para entrada de dados no terminal <br> <br>

Essa primeira parte do projeto foi realizada apenas com 3 principais tecnologias, sendo elas: <br> <b>Java</b> puro para treinar sintaxe, <b>Scanner</b> para entrada de dados no terminal para testar o sistema e <b>ArrayList</b> para guardar objetos/informações e poder buscar esses objetos/informações guardados em memória com o sistema em execução, uma vez que não foi usado banco de dados.

Este projeto não será mais evoluído neste repositório para preservar os commits feitos, e seguir boas práticas do mercado, além de futuramente poder comparar este projeto simples, feito com Java e Scanner, com o projeto final utilizando Spring boot, mySQL, React, entre outras tecnologias. <br>
